# IJMM Restaurante

Sistema para restaurantes: mesas, comandas por área de preparación (cocina, bar…), app de meseros en el celular y caja. Funciona en tu red local, sin internet. Desarrollado por [IJMM System](https://ijmmsystem.com/productos/ijmm-restaurante).

## Descarga

**Versión 1.0.10** — Windows 10/11 (64 bits) — 89 MB

[Descargar IJMM-Restaurante-Setup-1.0.10.exe](https://github.com/johao2/ijmm-restaurante/raw/main/IJMM-Restaurante-Setup-1.0.10.exe)

SHA-256: `ae02218d98fae69d36c66142da40d044c515eb891ff4da18b8960523e5efcf63`

## Instalación

1. Ejecuta el instalador en la computadora de caja. Si Windows muestra "Windows protegió su PC", elige **Más información → Ejecutar de todas formas**.
2. Abre **IJMM Restaurante** desde el escritorio.
3. Registra tu negocio y el número de mesas; la configuración guiada te ayuda con tiqueteras, meseros y menú.
4. Los meseros instalan la app **IJMM Meseros** escaneando el código QR de *Ajustes → Meseros y celulares*.

Incluye **15 días de prueba** con todas las funciones. Después, cómprala desde el mismo sistema (Licencia → Comprar en línea) o escríbenos en https://ijmmsystem.com/contacto
